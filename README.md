# Folhetim

Plataforma de streaming de novelas (Projeto avaliativo de Interação Humano Computador, etapa 1).

## Como rodar
1. Instale o Node.js (versão 18 ou mais nova)
2. `npm install`
3. `npm start`
4. Abra http://localhost:3000

Se você já tinha rodado uma versão antiga, apague o arquivo `banco/folhetim.db` antes de rodar de novo.
